This is a personal game project demo to improve my skills in godot and video game development
The idea of the game is to be a 2d platformer, possibly puzzles implemented as well

I am still working on it so it only has basic movement, items, player, and levels.
this game currently has a main menu and 3 playable levels one of which is the tutorial

Learned Skills

-Creating unique objects  (scenes) that triggers unique events when interacting with the player  Ex: heals, damages, change velocity
Creating scenes that can be components to other Objects, creates flexibility ain creating unique objects. (has-a relationship)
  For Example - (killzone) is an area2d scene that can be added to any new object to give it a zone that damages the player
Custom camera movement
Custom player movement ( jumps higher the longer you hold the jump button)
Physics engine understanding
